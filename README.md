# Dahlias

A personal dahlia breeding tracker for iPhone. It covers crosses, seed, seedlings,
season-by-season trials, photos and tubers.

- Web app hosted on GitHub Pages: <https://dyjoso.github.io/dahlias/>
- Data and photos are stored in Supabase
- Spec: [SPEC.md](SPEC.md)
- Database setup: [supabase/SETUP.md](supabase/SETUP.md)
